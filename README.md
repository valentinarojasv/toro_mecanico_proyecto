# toro_mecanico_proyecto
# Toro Mecánico

## Descripción del proyecto
Videojuego 2D desarrollado en Godot 4.7.2 utilizando GDScript.

El objetivo del videojuego es mantener el equilibrio sobre un toro
mecánico durante el mayor tiempo posible, superando diferentes
desafíos interactivos (QTE).

## Herramientas utilizadas
- Godot 4.7.2
- GDScript
- Git y GitHub

## Avances realizados
- Configuración inicial del proyecto.
- Organización de carpetas y escenas.
- Implementación del escenario principal.
- Creación de la estructura del toro mecánico.
- Creación del jinete.
- Preparación de cuatro animaciones del jinete.
- Programación del balanceo automático del toro.
- Creación de un Resource para configurar el movimiento.

## Próximas etapas
